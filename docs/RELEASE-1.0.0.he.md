# גרסת הפצה 1.0.0 — 26.10.2026

התוצר להפעלה הוא `release/1.0.0/Win11Updater-1.0.0.exe` בלבד. אין דרישה להתקנת SDK או להורדת תלות נוספת במחשב Windows 11 x64 עם .NET Framework המובנה. המתקין שמופעל הוא Installation Assistant המקורי של Microsoft, שהכלי מוריד ומאמת בזמן השימוש. אין ISO, יצירת USB, החלפת מתקין או שינוי קובצי Microsoft.

## מה נסגר לקראת ההפצה

- מסלול העדכון ועקיפות הזכאות של 0.2.0 נשמרו, כולל ברירות המחדל. לא נוספו דגלי עקיפה חדשים.
- מספר גרסה אחיד 1.0.0 בכותרת, ביומן, במאפייני ה־EXE ובאריזת ההפצה.
- שמות הפקדים עודכנו לעברית פשוטה; האפשרויות הניסיוניות נשארו מסומנות ככאלה.
- פקיעת זמן המתנה בהורדת HTTP מומרת ל־TimeoutException ומקבלת את ניסיונות ההורדה החוזרים. היא אינה מוצגת כביטול שביקש המשתמש.
- אחרי חלון האישור לשחזור נבדק שוב שאין מתקין פעיל, לפני תחילת כתיבות השחזור.
- נוספה אריזה שמוודאת שגיבוב ה־EXE ודוח הבדיקות תואמים לקבלת האימות של הבנייה. תיקיית ההפצה כוללת קובץ הפעלה, הוראות קצרות, מקור, רישיון, מניפסט וגיבובי SHA256.
- נשמרה תאימות למיקום הגיבוי, למבנה `state.json` ולנעילה הגלובלית של הגרסאות הקודמות. אין איפוס אוטומטי של גיבויים או של הגדרות ממחשב שכבר השתמש בכלי.

## תוצאות בדיקה של קובץ ההפעלה הנוכחי

ב־26 באוקטובר לפי שעון ישראל נבנתה הגרסה במהדר C# של .NET Framework x64, עם אזהרות כשגיאות. עברו 30 בדיקות אוטומטיות, כולל בדיקת Timeout חדשה. דוח הבדיקות והגיבובים המדויקים נכללים ב־`validation/1.0.0` בחבילת המקור. בדיקות HTTP ומדיניות המטמון כוללות סימולציות עם אימות חתימה מדומה היכן שמצוין; הן אינן מחליפות אימות Authenticode אמיתי.

בנפרד בוצעה הורדה אמיתית של האשף ממיקרוסופט באמצעות EXE הגרסה הנוכחית, ואימות WinVerifyTrust הצליח. מיד אחריה נבדק שימוש חוזר באותו קובץ מהמטמון, שוב לאחר אימות חתימה. הקובץ שנבדק:

```text
Version: 1.4.19041.7779
Signer: Microsoft Corporation
SHA256: A54D847BC7DA71E7E291BA321C80CF6E2F0345B20E399F11670378912D0DB14A
```

בוצע רינדור חזותי של חלון הגרסה מחוץ למסך. בדיקות Registry אמיתיות בענף HKCU מבודד בוצעו בגרסה המקורית, כפי שמתועד במסמך הבדיקות ההיסטורי; הן לא נחשבות כאן כניסוי שדרוג Windows חדש.

## דיווח המשתמש לעומת הבדיקה המקומית

המשתמש דיווח שהכלי הקודם עבד, ושהחשד לכשל נבע מכך שלא היה חיבור לאינטרנט. בהמשך אישר במפורש שההתקנה במחשב הלא נתמך הסתיימה ושנכנס ל־Windows המעודכן. זהו דיווח הצלחה של המשתמש לאחר שדרוג במחשב הבדיקה שלו. גרסת הכלי המדויקת ובילד Windows אחרי השדרוג לא נמסרו, ולכן ההצלחה אינה מיוחסת דווקא לגרסה 1.0.0. אין להסיק ממנה אימות עצמאי של שימור כל יישום או הבטחת הצלחה בכל מחשב.

בבדיקה המקומית לא הופעל אשף Microsoft, לא הורדה מערכת הפעלה, לא נכתבו ערכי זכאות למחשב העבודה, לא בוצע שדרוג ולא בוצע אתחול. לא נבדקה אינטראקטיבית בקשת UAC בחשבון אחר. אין הבטחה למעבר כל בדיקה מאוחרת של Microsoft או לעבודה על כל מחשב לא נתמך. הנתיב הניסיוני של LabConfig ושל SkipCompatCheck נשאר בעל אותם גבולות שתועדו במחקר.

## חתימת מפיץ והפצה

קובץ הכלי אינו חתום בתעודת מפיץ. אין תעודת חתימה שסופקה או אושרה לשימוש, ואין חתימה עצמית שמתחזה ל־Microsoft. Windows עשוי להציג „מפרסם לא ידוע” או לחסום את הקובץ לפי מדיניות המחשב. אין להבטיח העדר אזהרות SmartScreen או להתנות שימוש בביטול הגנות. חתימת Microsoft של האשף נבדקת בזמן אמת בנפרד, והאימות שלה אינו מוקל בעקבות כשל רשת.

אם המפיץ מוסיף חתימת קוד לקובץ, הוא משנה את ה־EXE ולכן צריך לעדכן את גיבובי ההפצה ולבדוק את הקובץ החתום. קוד המקור זמין לשיתוף ברישיון MIT. מאגר הפרויקט המיועד הוא `moshiach770chabad749-hue/win11-assistant-bridge` ב־GitHub, וקובצי ההפצה מיועדים לפרסום ב־Releases; קובצי Microsoft אינם נכללים בהם.
