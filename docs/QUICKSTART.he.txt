מעדכן Windows 11 — גרסה 1.0.0

לשימוש צריך רק את Win11Updater-1.0.0.exe.
זהו כלי עצמאי להפעלת Windows 11 Installation Assistant המקורי של Microsoft מתוך מחשב שכבר מותקן בו Windows 11 x64.
נדרש חיבור לאינטרנט. האשף המקורי מוריד את Windows ומתקין אותו; אין צורך ב־ISO או ביצירת USB.
הכלי אינו מוצר של Microsoft וקובץ ההפעלה שלו אינו חתום בתעודת מפיץ. חתימת Microsoft של האשף שמורידים נבדקת בנפרד. אין לבטל הגנות Windows כדי להפעילו אם מדיניות המחשב חוסמת אותו.

הפעלה רגילה
1. גבה את הקבצים החשובים, שמור עבודה פתוחה וחבר מחשב נייד לחשמל.
2. לחץ פעמיים על קובץ ההפעלה ואשר את בקשת הרשאות המנהל הרגילה.
3. סמן את אישורי הגיבוי והחומרה הלא נתמכת. במחשב לא נתמך ניתן לבחור גם בשתי העקיפות הנוספות המסומנות כניסיוניות. הן אינן מבטיחות מעבר של כל בדיקה.
4. השאר מסומן שימוש באשף שכבר הורד, ולחץ „1. הורדה והכנה”. הכלי יוודא חתימת Microsoft, יגבה את ההגדרות ורק אז יחיל את עקיפות הזכאות.
5. להפעלת ההתקנה סמן בנפרד את האישור להתקנה ולאתחולים בהמשך, ולחץ „2. הפעלת אשף Microsoft”. אשר גם את חלון האישור הבא.
6. המשך בחלון של Microsoft ואשר שם את תנאי הרישיון. אם לא ניתן לשמור קבצים ויישומים — בטל את ההתקנה.
7. בזמן שההתקנה עובדת, השאר את האשף פועל. פס ההתקדמות בכלי מתייחס רק להורדת האשף הקטן; התקדמות התקנת Windows מוצגת בחלון Microsoft.

אין אינטרנט או שההורדה נכשלת
לחץ „בדיקת אינטרנט”. הבדיקה אינה משנה DNS, Proxy או Firewall. ההורדה תנסה שוב עד שלוש פעמים בכשלים זמניים. עותק שכבר הורד מתקבל רק אחרי אימות חתימה מחדש; עותק ישן עשוי לדרוש אישור נוסף. אפשר גם לבחור אשף Microsoft מקורי שהורד מראש באמצעות „בחירת אשף מקומי”. עדיין נדרש חיבור תקין כדי שהאשף יוריד את Windows, ולעיתים גם כדי לאמת תעודות.

ניסיון קודם הופסק
לאחר שידוע שההתקנה הקודמת הסתיימה או בוטלה, פתח את הכלי והשאר אותו פתוח לדקה ללא מתקינים. סמן מחדש אישור התקנה ואתחולים ולחץ „2. ניסיון נוסף באשף”. הגיבוי המקורי נשמר. Microsoft מחליטה אם להמשיך בקבצים הקיימים או להוריד מחדש; אין הבטחה להמשך מאותו אחוז.
כדי לשנות את הסימונים לפני ניסיון אחר, לחץ „שחזור הגדרות” לאחר שההתקנה הסתיימה או בוטלה. שחזור זה מחזיר הגדרות Registry בלבד; הוא אינו מסיר Windows או מחזיר גרסת מערכת קודמת.

ביטול ובירור תקלות
„ביטול הורדה” מבטל רק את ההכנה והורדת האשף מצד הכלי. הוא אינו מפסיק את מתקין Windows.
סגירת הכלי אינה עוצרת את אשף Microsoft או את האתחולים שאושרו לו.
אם האשף מציג שגיאה או שאין התקדמות, לחץ „שמירת יומן ל־ZIP” ושמור ראיות. החבילה עשויה להכיל שמות יישומים ונתיבים פרטיים; בדוק לפני שיתוף. אחוז כמו 70% לבדו אינו מוכיח שההתקנה נכשלה.
גיבוי ויומן נשמרים ב־%ProgramData%\Win11AssistantBridge.

מגבלות
עקיפות הזכאות אינן מוסיפות RAM, TPM, Secure Boot או הוראות מעבד חסרות. לא כל מחשב לא נתמך יוכל להשתדרג. הכלי חוסם הפעלה כשחסרות הוראות SSE4.2/POPCNT, כשאין די מקום להכנת ההורדה או כאשר נצפית התקנת מערכת פעילה.
נדרשת הסכמה מפורשת לפני שהאשף מופעל, והיא כוללת את האתחולים שהוא עשוי לבצע בהמשך. אין הבטחה לעצירה נוספת לפני כל אתחול.
שדרוג מלא לא בוצע על ידי מפתח הכלי בסביבת הבדיקה. תוצאות בדיקות הרכיבים וקוד המקור מצורפים בנפרד.

בנייה מקוד מקור
ב־Windows x64 עם .NET Framework 4.8: הפעל build.ps1 -RunTests מתוך תיקיית המקור.
לאריזת גרסת הפצה מחדש: package-release.ps1. האריזה מאמתת שקובץ ההפעלה ודוח הבדיקות תואמים לקבלת האימות של הבנייה.
